# 📊 Ad-Hoc Data Request Bot

Ask any business question in plain English — get instant answers, charts, and downloadable data.

## 🚀 Live App
👉 **[Click here to open the app](https://adhoc-bot-bt74qdswqj7wulbszsb3ka.streamlit.app)**

## 💡 What can it do?
- Answer business questions in plain English
- Generate SQL queries automatically
- Create charts and visualizations
- Analyze why metrics are high or low
- Upload your own dataset (CSV or Excel)
- Download results as Excel files

## 🧠 Powered by
- [Streamlit](https://streamlit.io) — UI
- [Groq + LLaMA 3.3](https://groq.com) — AI
- [DuckDB](https://duckdb.org) — SQL engine
- [Plotly](https://plotly.com) — Charts
